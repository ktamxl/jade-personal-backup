## 核心思想摘要

### 一、帝國底層密碼
- 1974年美國-沙特秘密協議：沙特以美元結算石油 → 強制全球持有美元儲備
- 石油美元的本質：不是一種貨幣，而是一種**強制性全球稅收系統**

### 二、霍爾木茲困局（2026年3月現況）
- 伊朗封鎖霍爾木茲海峽 → 油價飆升 → 美元短期走強（石油美元機制表面正常）
- 但伊朗自己有管道繞過海峽（霍爾木茲-卡爾格島管線）
- 表面是能源危機，實質是：**誰撐不住了？**

### 三、日本的困局與日俄管道邏輯
- 日本零本土石油，完全依賴進口能源
- 高市早苗飛往阿拉斯加 → LNG合作協議（政治表演）
- **薩哈林2號秘密**：日本繼續購買俄羅斯LNG（9-10%），美國豁免
- 地理邏輯：薩哈林→北海道幾百公里，最短跨國能源路線

### 四、核心假設：日俄管道 = 本世紀最重要地緣基建
- 日本走向日俄直輸管道 + 日圓-盧布結算
- 中國已有「西伯利亞力量管道」以人民幣結算（每年數百億立方米）
- 連鎖效應：
  日圓-盧布結算 → 日圓回流 → 日本減持美債 → 美元走弱 + 美債殖利率上升 → 石油美元公信力裂縫 → 各國加速去美元化 → **黃金超級周期重啟**

### 五、沙特早就動手
- 沙特2022年起已接受人民幣結算部分石油交易
- 中國是沙特最大石油客戶
- 巴西、俄羅斯、印度推進BRICS+本幣結算框架
- **「美元霸權不是一夜崩塌，是幾十個「我們也可以用別的貨幣」的選擇慢慢磨損」**

### 六、黃金在等什麼？
- 黃金真正爆發等的不僅是通脹，而是**信任的喪失**
- 當市場開始問：「美元不再是石油唯一貨幣，美元的估值基礎是什麼？」
- 黃金不是對沖工具，而是**替代錨**
- 1971年美元脫離金本位後，黃金在接下來十年漲超過**二十倍**

### 七、能源進口國的純粹理性計算
- 去美元化不是意識形態，是**企業採購決策**
- 美國的選擇：「制裁你的能源供應商」
- 俄羅斯的選擇：「給你管道、給你本幣結算、不附帶政治條件」

### 八、Ken的三大持倉主題
1. **黃金** — 紫金礦業、黃金ETF、礦業基金（石油美元體系鬆動直接受益）
2. **能源** — 中海油（中海油）。中國能源需求不因去美元化消失，反而因人民幣結算更有優勢
3. **AI** — MiniMax、智譜AI（中國AI邊際成本趨零，與能源格局無關，與未來生產力爆炸直接相關）

### 九、結語金句
- 「沒有帝國是一夜崩塌的」
- 「**能源，永遠是主角。貨幣，只是能源的影子。**」
- 「當影子開始與主角分離，那是一個值得長期關注的信號。」

## 與Jade之前的建議關聯

### 為何這支論文支持我之前對黃金的建議？

Ken在論文中提到：霍爾木茲封鎖 → 油價飆升 → 美元短期走強 → **黃金價格受壓**

這是一個**短中期矛盾**：
- 結構上：去美元化 → 黃金超級周期 ✅（Ken和我都認同）
- 短線上：地緣危機 → 美元走強 → 黃金短期受壓（這正是2026年3-4月的情況）

**之前我建議Ken在六月前減持黃金的邏輯**：
- 結構性黃金牛市不變
- 但六月全球市場潛在崩潰 → 流動性緊張 → **黃金在短期恐慌中仍可能被贖回/拋售換現金**
- 這個論文印證了：「美元短期走強壓制黃金」的邏輯在現階段已發生

所以：
- **黃金長線不走**
- **但六月前適度減持至核心持倉，保留現金**，等待八月（戊申土氣 + 用神到位）重新加倉
